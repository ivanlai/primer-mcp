## Parent Epic
[[EP-001]]

## Context
primer-mcp was built with hard gates — GateError blocks operations when prerequisites are not met (no ADR before stories, no story before tasks, no start before complete). This made the workflow deterministic and testable, but in practice it creates friction: bugs do not fit the hierarchy, manual commits bypass the two-phase gate, and the enforcement feels like the bureaucracy the tool was meant to replace. The original vision was to simplify agile with AI, not to build a stricter Jira. The AI is the interface — it should carry the process burden, not the user.

## Decision
Replace hard gates with soft nudges. The server warns and advises when a step is skipped but does not block the operation. The AI, always present in the conversation, drives the workflow: suggesting ADRs when they would help, prompting for task completion when it observes work is done, recommending the bug-fix story for small fixes. The two-phase completion concept survives as a quality practice the AI manages, not a ceremony the user remembers.

## Alternatives Considered
- Keep hard gates (status quo) — deterministic and testable, but creates friction for reactive work and puts the process burden on the user rather than the AI. Rejected because it contradicts the vision of AI-assisted simplicity.
- Make gates configurable per-project (require_adrs flag, etc.) — adds complexity without solving the core issue. The problem is not that some projects want gates; it is that gates are the wrong metaphor when the AI is the interface.
- Remove all structure — no workflow, just markdown files. Rejected because the planning-first approach has real value; the issue is how it is enforced, not whether it exists.

## Consequences
The tool becomes more pleasant to use but relies on AI quality — tool descriptions and prompts become the primary steering mechanism and must be excellent. Users can skip steps, so backlogs may be less tidy. The rigid test suite for gate enforcement will need reworking. TK-023 (optional ADR gate) is superseded by this broader change.
