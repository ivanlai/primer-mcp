## Parent Story
[[ST-020]]

## What to do
Review every test across the suite. Each test must verify a real behaviour that could break if the code were modified without sufficient thinking. Remove any fillers — tests that exist for coverage or quantity, that pass trivially, or that only check message strings without verifying actual state. This was prompted by finding weak tests during the ST-021 soft-gate rewrite.

## Testable Outcome
Every test can fail for a real reason; no test only asserts message strings without checking state

## Completion Notes
Audited all 218 tests across 8 test files. Found five trivially-passing tests: test_updated_date_refreshed in TestStartTask, TestCompleteTask, TestVerifyTask, TestCompleteSpike (test_tickets.py) and test_updated_date_is_bumped (test_query.py). All used assert after.updated >= before.updated, which always passes since both dates are date.today(). Fixed by backdating the ticket to yesterday before each operation, then asserting == datetime.now(UTC).date().
