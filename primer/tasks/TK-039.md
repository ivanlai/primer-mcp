## What to do
**What's gone wrong:** CLAUDE.md still claims gate 3 is enforced — it lists "Cannot call `verify_task` before `complete_task` has been called" under "Workflow gates (enforced by the server — never bypass)". But `verify_task` (tickets.py:441) deliberately proceeds from todo/in-progress with only a nudge — ST-021 shifted the workflow from enforcement to guidance and this gate was softened as part of that. The checked-in doc now misdocuments shipped behaviour, pre-release.

Fix the doc, not the code: update the CLAUDE.md gate list (and check docs/architecture.md and the README for the same claim) so only the gates the server actually enforces are listed as enforced. The two hard gates that remain are the parent-Epic requirement for ADRs and the parent-Story requirement for Tasks.
