## Parent Epic
[[EP-001]]

## What
Project navigation and read/update tools built on a networkx dependency graph. get_next_action returns the first unmet workflow gate, else the next ready ticket in topological order. get_ticket and list_tickets give agents read access without filesystem permissions. update_ticket handles post-creation edits: status, blocked_by edges, body sections, external_ref.

## Acceptance Criteria
- [ ] get_next_action correctly identifies blockers and names what blocks each ticket
- [ ] update_ticket rejects edge updates that would create a dependency cycle, leaving the file unchanged
- [ ] Derived done-ness cascades into parent story and epic files, both directions
- [ ] update_ticket rejects status changes on terminal tickets
- [ ] list_tickets filters by type and status

## Definition of Done
- [ ] Unit tests cover every ladder rung and every gate
- [ ] ruff, mypy strict and pytest all green
- [ ] get_next_action run against this repo's own primer/ store returns the expected next task
