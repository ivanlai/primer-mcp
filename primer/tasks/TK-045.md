## What to do
Submit primer-mcp to the mcp.so MCP server directory so it's discoverable by other users.

## Prerequisites

1. **PyPI publication** — primer-mcp must be published on PyPI so users can install via `uvx primer-mcp`. If not already published, do this first.
2. **README quality** — the GitHub README is the storefront on mcp.so. It should cover what the server does, how to install it, and how to configure it in Claude/other MCP clients.
3. **MCP JSON config example** — include a snippet in the README showing how to add primer-mcp to `~/.mcp.json` or Claude Desktop's config, since that's what users copy-paste.

## mcp.so submission process

1. Go to https://mcp.so/submit
2. Submit the public GitHub repo URL
3. Complete the draft information (name, description)
4. Save — it auto-publishes on save

## Optional: Official MCP Registry

Also consider listing on the official registry at registry.modelcontextprotocol.io:
- Add a `server.json` file to the repo with schema, name, description, version, and package details
- Install `mcp-publisher` CLI tool
- Run `mcp-publisher login github` to authenticate
- Run `mcp-publisher publish` to submit
- Automatic validation, no manual review
