## Parent Story
[[ST-020]]

## What to do
get_next_action currently returns exactly one suggestion. Change it to present available options (open stories, ready tasks) with a recommendation for which to pick up first. Fits the guidance-over-enforcement philosophy — the user chooses, the tool advises.

## Testable Outcome
get_next_action returns a list of actionable items with one highlighted as recommended

## Dependencies
- (none)

## Completion Notes
Renamed `get_next_action` to `list_actionable`. The old tool returned a single deterministic instruction; the new one returns epic context (goals, story coverage, urgent gates) and a table of all actionable items. The recommendation is now the LLM's job — the tool description instructs it to check goal coverage, read relevant tickets, and recommend based on impact. Tested with a fresh Sonnet subagent: it caught a planning gap (5 goals / 1 story) and recommended more stories before execution.

Key decisions:
- Removed the `→` recommendation marker — a sort-by-ID heuristic was worse than no recommendation
- Merged childless-stories and ready-tasks into one combined table so the user sees all options
- Added Story/Item columns showing the hierarchy
- Summary column uses testable_outcome (tasks), question (spikes), or first acceptance criterion (stories)
- Tool description encodes the full reasoning loop: check goal coverage → finish urgent items → read tickets → recommend with reasoning
