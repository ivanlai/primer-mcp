## What to do
When an epic's or story's derived status transitions to done (all children finished), include a nudge in the tool response prompting the agent to review the ticket body with the user — are goals/acceptance criteria still accurate, does anything need updating? This could trigger from verify_task or complete_task when the last child finishes. The nudge is a suggestion, not a gate.

Verify by running the nudge against EP-001's existing stale tickets — the review doubles as cleanup.
## Testable Outcome
Completing/verifying the last child under an epic or story produces a response that nudges the agent to review the parent's content with the user. EP-001's stale tickets are updated as part of verification.
