## Parent Story
[[ST-020]]

## What to do
Add a require_adrs flag (default true) to config.yaml. When false, create_story skips the ADR check, so small/solo projects can go straight from epic to stories.

## Testable Outcome
create_story succeeds without an ADR when require_adrs is false; gate still enforced when true

## Dependencies
- (none)

## Completion Notes
ST-021 already shifted the ADR gate from a hard block to a nudge — `create_story` succeeds and appends a tip. A `require_adrs` config flag was planned but deemed unnecessary: the nudge is the right level of guidance, and a flag to suppress it adds complexity without real value. The actual work was updating stale docs (architecture.md, CLAUDE.md) that still described the ADR check as a hard gate.
