## Parent Epic
[[EP-001]]

## What
Record which ADRs a story rests on, so the link between a decision and the work it shapes lives in the store rather than only in commit messages. Also gives export_graph a reason to render ADR nodes, which today hang off an epic with nothing explaining why they matter.

## Acceptance Criteria
- [ ] A story records the ADRs it rests on; empty is valid
- [ ] Referenced ADRs must exist under the story's parent epic
- [ ] The create_story gate is unchanged — the epic still only needs one ADR

## Definition of Done
- [ ] Existing stories are backfilled once update_ticket exists
