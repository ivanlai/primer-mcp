## Parent Story
[[ST-020]]

## What to do
Two parts:

1. Remove the static "Child ADRs" and "Child Stories" sections from the epic body template in templates.py — they go stale immediately, and the graph is the source of truth for children.

2. When an epic's or story's derived status transitions to done (all children finished), include a nudge in the tool response prompting the agent to review the ticket body with the user — are goals/acceptance criteria still accurate, does anything need updating? This could trigger from verify_task or complete_task when the last child finishes. The nudge is a suggestion, not a gate.

Verify by running the nudge against EP-001's existing stale tickets — the review doubles as cleanup.
## Testable Outcome
Epic template no longer includes Child ADRs or Child Stories sections. Completing/verifying the last child under an epic or story produces a response that nudges the agent to review the parent's content with the user. EP-001's stale tickets are updated as part of verification.

## Completion Notes
Two changes:
1. Removed "Child ADRs" and "Child Stories" sections from `epic_body` in templates.py — the graph is the source of truth for children.
2. Added nudge in `recompute_parents` (graph.py) when a parent transitions to done: suggests the agent review goals/success criteria (epics) or acceptance criteria/definition of done (stories) with the user. The nudge is appended to the tool response from verify_task and complete_spike.
