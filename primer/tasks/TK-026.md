## What to do
get_next_action has no visibility into git — if a user commits manually without closing the two-phase gate, it keeps suggesting work that is already done. Explore having get_next_action scan git log for commits mentioning task IDs and surface a nudge to close the gate. Needs thought on commit message conventions and false positives.

## Testable Outcome
get_next_action detects at least one case where a task ID appears in a recent commit but the task status has not advanced
