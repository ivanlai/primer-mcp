## What to do
Record the schema version when a project is initialised and check it when the store is read. Replace the validation error that currently tells users to hand-edit or remove a ticket.

## Testable Outcome
A store stamped with a future version is rejected naming the mismatch; an existing store still loads; the invalid-ticket error no longer advises hand-editing.

## Dependencies
- (none)

## Completion Notes
Relaxed the models to tolerate unknown keys, which removed the need for the version gate and migration path. Stamp kept, never enforced. ADR-007.
