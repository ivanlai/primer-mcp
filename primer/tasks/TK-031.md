## What to do
Review every test across the suite. Each test must verify a real behaviour that could break if the code were modified without sufficient thinking. Remove any fillers — tests that exist for coverage or quantity, that pass trivially, or that only check message strings without verifying actual state. This was prompted by finding weak tests during the ST-021 soft-gate rewrite.

## Testable Outcome
Every test can fail for a real reason; no test only asserts message strings without checking state
