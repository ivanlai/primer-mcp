## Parent Epic
[[EP-001]]

## What
Record which commit a task lands in, so the link between a ticket and its implementation lives in the store rather than only in free-text evidence strings. Gives get_ticket a structured field to show and export_graph a reason to annotate task nodes with their commit.

## Acceptance Criteria
- [ ] complete_task and/or verify_task accept an optional commit parameter
- [ ] The commit hash is stored in a dedicated field on the task (not just external_ref)
- [ ] get_ticket displays the commit reference when present
- [ ] An invalid commit hash format is rejected at input
- [ ] Existing tasks without a commit ref continue to work unchanged

## Definition of Done
- [ ] Unit tests cover the new field, validation, and display
