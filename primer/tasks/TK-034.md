## What to do
**What's gone wrong:** The no-ADR gate suppresses everything (store.py:377) — `list_actionable` short-circuits with "EP-001 has no recorded decisions yet" before it even checks for stories. An epic with stories and todo tasks but no ADR gets only "record an ADR first", forever: no goals, no story coverage, no actionable items. But `create_story` deliberately allows skipping ADRs (nudge only, per ST-021's shift from enforcement to guidance), so the two disagree — and the short-circuit message even suggests creating stories that already exist.

Fix: when the epic has stories, show the normal output and demote the missing-ADR message to a nudge line. Only short-circuit when the epic has neither ADRs nor stories (nothing to list anyway).

## Testable Outcome
An epic with stories and todo tasks but no ADR still gets the full epic context and actionable table from list_actionable, with the ADR reminder as a nudge rather than a short-circuit.

## Dependencies
- (none)

## Completion Notes
Demoted the no-ADR gate from a short-circuit `return _answer(...)` to an end-of-output nudge. The short-circuit now only fires when the epic has neither ADRs nor stories (nothing to list anyway). When stories exist, the full epic context and actionable table render normally, with a "Note: EP-001 has no ADRs" reminder appended.
