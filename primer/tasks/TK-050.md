## What to do
When an epic's derived status transitions to done (all children finished), include a nudge in the tool response prompting the agent to review the epic with the user — are goals still accurate, did success criteria change, does anything need updating? This could trigger from verify_task or complete_task when the last child finishes. The nudge is a suggestion, not a gate.

## Testable Outcome
Completing/verifying the last child under an epic produces a response that nudges the agent to review the epic's content with the user
