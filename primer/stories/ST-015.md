## Parent Epic
[[EP-001]]

## What
Record a schema version in the store so a future field change can be detected rather than bricking it. Must land before the first release: a version stamp cannot be added retroactively, because stores already in the wild without one are indistinguishable from new ones.

## Acceptance Criteria
- [ ] init_project records the schema version in config.yaml
- [ ] A store written by a newer primer-mcp is rejected with a message naming the mismatch
- [ ] An invalid ticket no longer tells the user to hand-edit or delete it

## Definition of Done
- [ ] No migration engine — nothing has shipped, so there is nothing to migrate from. Add one when a field actually moves
