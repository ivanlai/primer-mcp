## What to do
Add an optional parent_id parameter to list_tickets. Filter stories by epic_id and tasks/spikes by story_id. Error if the parent does not exist.

## Testable Outcome
list_tickets(parent_id="ST-008") returns only tasks and spikes under that story

## Dependencies
- (none)

## Completion Notes
Added optional `parent_id` parameter to `list_tickets` in query.py and server.py. When set, validates the parent exists then delegates to the existing `children_of()` helper from graph.py to scope results to direct children. Type and status filters compose on top. Four tests cover: story children, epic children (ADRs excluded), combined filters, and nonexistent parent error.
