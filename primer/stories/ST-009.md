## What
Implement the MCP Prompt primitives. plan_story scaffolds a planning conversation before a story is created. export_jira scaffolds export via the client's own Jira MCP server following the field mapping in architecture.md. import_jira traverses a Jira epic and creates the hierarchy locally in workflow-gate order.

## Acceptance Criteria

- export_jira instructs the agent to record issue keys in external_ref so re-export updates rather than duplicates
- import_jira creates tickets in gate order: epic, ADR, stories, tasks
